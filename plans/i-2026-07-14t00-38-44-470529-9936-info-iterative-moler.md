# Fix Propshaft deprecation exception on edge Rails

## Context

Development requests to `GET /` fail with `ActiveSupport::DeprecationException` because:

- The app runs Rails `8.2.0.alpha` (edge), which deprecated `Mime::EXTENSION_LOOKUP`.
- Propshaft `1.3.2` still calls it in `lib/propshaft/load_path.rb:55` (`cache_sweeper`, invoked
  per-request in development to watch asset directories).
- `config/environments/development.rb:67` sets `config.active_support.deprecation = :raise`, so the
  deprecation warning becomes a raised exception.

Nothing in the application code is at fault; this is a gem-compatibility lag.

## Plan

1. Run `bundle update propshaft`. If a newer release removes the `Mime::EXTENSION_LOOKUP` usage,
   done.
2. If no fixed release exists yet, point the Gemfile at upstream main:
   `gem "propshaft", github: "rails/propshaft"` — a temporary measure while the app tracks edge
   Rails; revisit when a fixed release ships.
3. Keep `config.active_support.deprecation = :raise` unchanged — it is intentionally strict.

## Verification

- Restart the dev server and request `GET /`; confirm no `DeprecationException` in the log and the
  page renders.
- `grep EXTENSION_LOOKUP` in the installed propshaft gem to confirm the call site is gone.
