# Alphabetical Ubiquitous Language

This file is the alphabetical index for DDD ubiquitous language.

Add terms under the first letter of the canonical English term. If a Japanese term is the canonical
domain term, place it under the first romanized letter and include the Japanese spelling in the term
heading.

## A

- **Account** — service-usage subject bound to an Identity. See
  `identity-account-organization-avatar.md`.
- **Avatar** — SNS-facing embodiment operated by Accounts (app/org only). See
  `identity-account-organization-avatar.md`.
